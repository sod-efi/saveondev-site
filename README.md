# saveondev.com

The Save On Dev website as plain files, served by GitHub Pages at https://saveondev.com.

It was copied from the old WordPress site on October 11, 2026, with the contact forms and the exit popup removed. There's no server, database or login, so there's nothing to hack or overload.

To change a page, edit its `index.html` (each page lives at its own path, like `how-we-help/index.html`) and push to `main`; GitHub Pages publishes it within a minute or two. How it was made and how to redo the copy: the private repo `sod-efi/saveondev`.

## Client previews

`previews/<name>-<random>/` holds design mocks to share with a client by link. Each page has `noindex` so search engines skip it, and nothing on the site links to it. The repo is public, so don't put anything private in a preview.
